# Step 4c: 立法建议立场（立法建议型）

## 任务
基于对现行法条的评析，提出具体的条文修改方案，并附立法理由。

## 输入
- Step 2 的现行法条分析：{大前提}
- Step 4a 的学界批评梳理：{学说清单}
- Step 4b 的评析结果：{学说评析}
- 域外立法参考（如有）：{域外法条}

## 执行步骤
1. 明确指出现行条文的具体不足（不能泛泛说"不完善"）
2. 提出具体的修改方案（精确到条款级别的变更）
3. 提供修改后的完整条文草案
4. 逐条列出立法理由

## 输出格式（JSON）
```json
{
  "本文立场": {
    "现行条文不足": "",
    "修改建议": "",
    "建议条文草案": "第X条  ...",
    "立法理由": ["理由1", "理由2"],
    "域外参考": null
  }
}
```

## 约束
- 条文草案必须表述规范，符合立法技术
- 每一条修改必须有对应的学理或实证依据
- 不得提出"建议立法机关完善相关规定"等空泛建议
