# Step 4a: 学说梳理

## 任务
梳理学界对该问题的几种主要学说/观点。
注意：这是学术梳理，不是立论。只需客观呈现学界有哪些观点。

## 输入
- Step 1 的法律问题：{核心问题}
- Step 2 的法条分析：{大前提}
- 相关文献的核心观点：{文献观点}

## 执行步骤
4a.1 检索文献库中与该法律问题相关的学说主张
4a.2 归纳各学说的核心主张和代表学者
4a.3 识别各学说之间的异同与传承关系
4a.4 按学术脉络排序（而非按立场对立）

## 输出格式（JSON）
```json
{
  "问题": "",
  "学说清单": [
    {
      "学说": "XX说",
      "核心主张": "",
      "代表学者": ["学者A"],
      "来源文献": ["L001"]
    }
  ]
}
```

## 约束
- 学说之间是"不同的学术回应"，不是"互相对立"
- 每种学说必须标注来源文献
- 遗漏重要学说 = 学术不完整
