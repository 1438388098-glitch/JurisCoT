# Step 1: 法律问题识别

## 任务
识别当前章节需要解决的核心法律问题。

## 输入
- 章节主题：{章节主题}
- 相关文献摘要：{文献摘要}
- 相关法条：{法条}

## 执行步骤
1. 分析章节主题，确定需要回应的核心法律问题
2. 将宽泛问题收窄为可论证的具体问题
3. 确认问题涉及的部门法和具体制度
4. 评估该问题的学术争议性（高/中/低）

## 输出格式（JSON）
```json
{
  "章节": "章节名称",
  "核心问题": "一句话概括的法律问题",
  "涉及部门法": "XX法",
  "涉及具体制度": "XX制度",
  "争议程度": "高/中/低",
  "问题拆解": ["子问题1", "子问题2"]
}
```
