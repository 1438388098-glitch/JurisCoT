# Step 4b: 学说评析

## 任务
逐一对各学说的理论依据和解释局限进行分析。

## 输入
- Step 4a 的学说清单：{学说清单}
- 相关文献的详细观点：{文献观点}

## 执行步骤
4b.1 对每种学说：提取其理论依据（基于什么法理基础）
4b.2 对每种学说：分析其解释力（在什么情景下适用良好）
4b.3 对每种学说：分析其局限（在什么情景下解释力不足）
4b.4 判断各学说之间的逻辑关系

## 输出格式（JSON）
```json
{
  "评析": [
    {
      "学说": "XX说",
      "理论依据": "",
      "解释力": "",
      "局限": "",
      "来源文献": ["L001"]
    }
  ],
  "学说关系": "各学说之间的逻辑关系概述"
}
```

## 约束
- 每种学说必须同时评析理据和局限，缺一不可
- "局限"是学术批评，不是否定该学说的价值
