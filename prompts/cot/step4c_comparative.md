# Step 4c: 比较分析立场（制度比较型）

## 任务
基于域外制度考察和国内制度评析，提炼可借鉴的经验，提出本土完善方案。

## 输入
- Step 4a 的学说/制度梳理：{学说清单}
- Step 4b 的评析结果：{学说评析}
- 域外法材料：{域外法条}
- 国内制度现状：{国内现状}

## 执行步骤
1. 概括域外制度的核心设计及其合理性
2. 逐一分析哪些做法值得中国借鉴，说明理由
3. 指出哪些域外做法可能不适应中国本土，说明原因
4. 提出具体建议方案

## 输出格式（JSON）
```json
{
  "本文立场": {
    "域外制度概述": "",
    "可借鉴之处": ["理由1", "理由2"],
    "需警惕之处": ["可能不适应的方面1"],
    "建议方案": "",
    "仍待研究的问题": null
  }
}
```

## 约束
- 借鉴建议必须基于域外制度的实际运作效果，不能仅凭条文文本
- 需警惕之处 = 域外做法在制度生态/文化背景下可能失效的方面
