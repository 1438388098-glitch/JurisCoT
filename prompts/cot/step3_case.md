# Step 3: 小前提构建（案件/事实分析）

## 任务
将具体案件/事实代入构成要件进行分析。
（仅案例分析型论文需要此步骤，理论辨析型跳过）

## 输入
- Step 2 的构成要件分析：{构成要件}
- 相关案例/事实描述：{案例素材}
- 案例评析类文献摘要：{文献}

## 执行步骤
3.1 提取案件/事实的关键情节
3.2 逐一比对各构成要件
3.3 识别案件中的争议焦点
3.4 结合学说观点分析各要件的满足程度

## 输出格式（JSON）
```json
{
  "案件名称": "",
  "案号": "",
  "关键情节": "",
  "要件比对": [
    {"要件": "要件一", "满足": true, "说明": ""},
    {"要件": "要件二", "满足": false, "说明": ""}
  ],
  "争议焦点": "",
  "学说参考": ""
}
```
