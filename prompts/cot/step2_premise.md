# Step 2: 大前提构建（法律规范分析）

## 任务
提取并解析适用的法律规范，拆解构成要件。

## 输入
- Step 1 输出的法律问题：{核心问题}
- **注入的法条原文**：{法条列表}（来自本地法条库，只能使用此列表中的法条）
- 法条解释类文献摘要：{文献}

## ⚠️ 法条引用硬约束（最高优先级）

- **你只能引用 `{法条列表}` 中列出的法条。**
- 引用时必须使用列表中提供的原文，不得改写法条内容。
- **绝对禁止**编造任何法条文号或内容。
- 如果推理过程中发现需要引用但 `{法条列表}` 中不存在的法条，
  在输出中添加 `补充需求` 字段说明，不得自行编造其内容。

## 执行步骤
2.1 从 `{法条列表}` 中确定适用的法律规范条文
2.2 解析规范的构成要件要素
2.3 检索学界对各构成要件的解释学说
2.4 选择适用于本问题的解释路径并说明理由

## 输出格式（JSON）
```json
{
  "适用法条": "《XX法》第X条",
  "法条来源": "legal_provisions",
  "法条原文": "",
  "构成要件": [
    {"要件": "要件一", "说明": ""}
  ],
  "争议要件": "最具争议的要件",
  "解释路径": "本文采取的解释路径",
  "理由": "",
  "补充需求": [
    {"需要补充法条": "XX法第X条", "原因": "讨论XX问题时需引用", "状态": "本地未收录"}
  ]
}
```

> 补充需求：仅当本地法条库未收录必要法条时填写此字段。可以为 null 或空数组。
