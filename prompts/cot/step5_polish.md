# Step 5: 学术表述润色 + 脚注生成

## 任务
将 CoT 推理结果转换为符合法学学术规范的连贯段落，并自动生成脚注。

## 输入
- 完整的 CoT 推理链（Step 1-4 的输出）
- 引用来源列表：{引用列表}

## 操作规范

### 正文润色
5.1 按「观点 → 论证 → 例证 → 小结」结构组织段落
5.2 法条引用格式：《中华人民共和国XX法》第 X 条
5.3 案例引用格式：（XXXX）XX 法 XX 字第 XX 号
5.4 使用恰当的法学学术衔接词（"然则""进而言之""有鉴于此"等）

### 脚注生成（法学论文核心格式要素）
5.6 正文中引用学者观点、数据、事实时，插入脚注标记（上标数字）
5.7 脚注格式遵循 GB/T 7714-2015 脚注格式：
    - 著作：作者，《书名》，出版社，年份，第X页
    - 期刊：作者，《文章名》，载《期刊名》XXXX年第X期，第X页
    - 学位论文：作者，《题名》，XX学校XX年硕士/博士论文，第X页
    - 法条：《中华人民共和国XX法》第X条
    - 案例：（XXXX）XX法XX字第XX号
5.8 同一文献第二次引用时使用简注：
    - 著作：作者，前注[X]，《书名》，第X页
    - 期刊：作者，前注[X]，《文章名》，第X页
5.9 脚注数字从 1 开始的连续编号，每章独立编号
5.10 引用标注映射到脚注：{引用列表} 中的每个来源 ID 对应一条完整脚注

## 输出格式（JSON）
```json
{
  "内容": "法学学术规范的中文正文（含脚注标记 [^1][^2]...）",
  "脚注列表": [
    {"编号": 1, "内容": "张明楷：《刑法学》，法律出版社，2020年，第245页", "来源文献": "L003"},
    {"编号": 2, "内容": "陈兴良：《正当防卫论》，中国人民大学出版社，2017年，第112页", "来源文献": "L005"}
  ],
  "引用列表": ["L003", "L005"]
}
```

## 约束
- 不得在润色过程中添加新的论证（推理已在 Step 4 完成）
- 脚注内容只能来自引用列表中的已有文献，不得编造新的文献信息
- 无法找到文献出处的论点标注为"本文认为"，不加脚注
- 脚注格式严格区分著作/期刊/学位论文/法条/案例五种类型
